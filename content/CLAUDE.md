# 유틀란트 해전 위키 — 스키마

## 개요

이 위키는 1916년 5월 31일~6월 1일 유틀란트 해전(독일명: 스카게라크 해전)에 대한 종합 지식 베이스다.
3권의 서적을 원천 자료로 하여 LLM이 작성·유지한다.

## 원천 자료 (raw/)

| 디렉토리 | 원제 | 저자 | 시점 |
|----------|------|------|------|
| `Yutland1916/` | *Jutland 1916: Death in the Grey Wastes* | Nigel Steel & Peter Hart | 영국 (참전자 증언) |
| `Skagerrak/` | *Skagerrak: The Battle of Jutland Through German Eyes* | Gary Staff | 독일 |
| `RulesofGames/` | *The Rules of the Game: Jutland and British Naval Command* | Andrew Gordon | 분석/교리 |
| `NJellicoe/` | *Jutland: The Unfinished Battle* | Nicholas Jellicoe | 현대 종합 (젤리코 손자) |

각 디렉토리에 `proofread/` (한국어 번역 텍스트)와 `pages/` (페이지 캡처 PNG)가 있다.
원천 자료는 **읽기 전용** — 절대 수정하지 않는다.

## 디렉토리 구조

```
wiki/
├── CLAUDE.md          # 이 파일 (스키마)
├── index.md           # 전체 색인 (카테고리별)
├── log.md             # 작업 로그 (시간순)
├── overview/          # 해전 개요
├── phases/            # 전투 단계별 상세 (시간순)
├── people/            # 인물 페이지
├── ships/             # 함선 페이지
│   └── classes/       # 함급 페이지
├── formations/        # 편제·부대 페이지
├── topics/            # 주제별 분석
├── sources/           # 원천 자료 요약
└── assets/            # 도판 (추출된 이미지)
    ├── maps/          # 전투 지도
    ├── photos/        # 함선·인물 사진
    └── diagrams/      # 포격도·진형도
```

## 페이지 작성 규칙

### 프론트매터 (YAML)
모든 위키 페이지는 다음 프론트매터를 포함한다:

```yaml
---
title: "페이지 제목"
aliases: ["영문명", "독일명"]  # 대체 이름
tags: [카테고리태그]
sources: ["Yutland1916", "Skagerrak", "RulesofGames"]  # 참조한 원천
created: 2026-04-09
updated: 2026-04-09
---
```

### 언어 규칙
- 본문은 **한국어**로 작성
- 고유명사(인명, 함선명, 지명, 부대명)는 첫 등장 시 **한국어 (원문)** 병기
  - 예: "젤리코 (John Jellicoe)", "자이들리츠 (SMS Seydlitz)"
  - 이후 등장 시 한국어만 사용
- 영국 함선: HMS 접두사, 독일 함선: SMS 접두사

### 링크 규칙 (Obsidian Wikilink)
- 내부 링크: `[[페이지명]]` 또는 `[[페이지명|표시텍스트]]`
- 다른 디렉토리 링크: `[[people/존_젤리코|젤리코]]`
- 도판 삽입: `![[assets/photos/파일명.png]]`
- 첫 등장 시에만 링크, 같은 문단 내 반복 링크 금지

### 출처 표기
- 본문 중 원천 인용 시 괄호로 표기: (Yutland1916, Ch.3) 또는 (Skagerrak, Ch.5)
- 페이지 하단에 `## 출처` 섹션으로 참조한 챕터 목록

### 도판 규칙
- 도판 파일명: `{book}_{page:04d}_{seq}.png` (예: `yutland1916_0145_01.png`)
- 도판 메타데이터: `assets/figures.md`에 테이블로 관리
- 도판 삽입 시 캡션 포함:
  ```
  > ![[assets/photos/yutland1916_0145_01.png]]
  > *캡션: 퀸 메리 호의 마지막 폭발 (IWM SP 1708)* — (Yutland1916, 도판 14)
  ```

## 인제스트 워크플로

1. 원천 챕터를 읽는다
2. 핵심 정보를 추출한다 (인물, 함선, 사건, 시간, 분석)
3. 기존 위키 페이지가 있으면 **업데이트**, 없으면 **신규 생성**
4. 관련 페이지에 교차 링크를 추가한다
5. `index.md`를 업데이트한다
6. `log.md`에 작업 내역을 추가한다

## 시간 표기
- 모든 시간은 **영국 시간** (GMT) 기준 (독일 시간은 +2시간)
- 형식: HH:MM (예: 15:48)

## 태그 체계
- 카테고리: `인물`, `함선`, `함급`, `전투단계`, `편제`, `주제`, `소스`
- 국적: `영국`, `독일`
- 함종: `전함`, `순양전함`, `경순양함`, `장갑순양함`, `구축함`, `기타`
- 시기: `해전전`, `해전중`, `해전후`
